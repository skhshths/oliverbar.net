What you get

Fast by design. Yours by default.

Everything a heavy browsing day needs, without the bloat — and nothing you didn't ask for.

Tiling panes & workspaces

Split any window toward your mouse and see several sites at once. Keep work and personal browsing on separate workspaces, and save layouts to reopen later.

Hundreds of tabs, little memory

Only the tabs you can see stay loaded. Hidden ones pause, then sleep, and wake instantly when you return. Music keeps playing.

Ads & trackers blocked

Built-in ad and tracker blocking, plus automatic cookie-banner hiding. Pages load lighter and cleaner with nothing to install.

A truly private workspace

One workspace saves nothing at all, is hidden from screenshots and screen sharing, and locks with a password when you step away.

Separate logins per workspace

Each workspace keeps its own sessions, so you can be signed into two accounts of the same site at the same time.

Make it yours — or make it fly

Twelve themes, a colour picker, animated backgrounds and audio-reactive visuals. Flip on ULTRASPEED to turn every effect off for raw speed.

Built for the keyboard

Everything a keypress away.

Tile, zoom, switch and search without touching the mouse. The command palette (ctrl shift p) does the rest — just type what you want.

Quick question: where did you hear about ULTRA?

Scanned · no malware found

That warning isn’t a virus alert.

Windows and macOS warn about ULTRA because it isn’t code-signed yet. Signing certificates cost $99–400 a year. The warning says nobody has vouched for who made the app. It doesn’t say anything about what it does. Here’s the evidence.

The short version

No malwareMicrosoft Defender scanned both downloads: no threats found.
Files are untouchedEach download matches the SHA-256 checksum GitHub published for it, byte for byte.
No telemetryNo analytics, tracking or usage reporting. An idle ULTRA contacts no ULTRA server.
Your data stays localHistory, bookmarks, tabs and settings are plain files on your computer, never uploaded.
No passwords storedULTRA never saves passwords, and imports never touch passwords or cookies.
Built in the openEvery release is built by GitHub Actions from public source code, not on someone’s laptop.

Which warning did you get?

“Windows protected your PC” (Microsoft Defender SmartScreen)
What it means
The file isn’t signed and few people have downloaded it yet, so it has no reputation with Microsoft.
What it doesn’t mean
It is not a detection. Defender found nothing; SmartScreen shows this same screen for every new unsigned app.
To open ULTRA
Click More info, then Run anyway.
“ULTRA can’t be opened because it is from an unidentified developer” (Gatekeeper)
What it means
The app isn’t signed with an Apple Developer ID or notarized by Apple.
What it doesn’t mean
Apple didn’t scan it and find a problem — Apple never saw the app.
To open ULTRA
Right-click ULTRA, choose Open, then Open again. You only do this once.
“ULTRA is damaged and can’t be opened”
What it means
macOS adds a quarantine flag to downloaded unsigned apps and words the warning this way.
What it doesn’t mean
The file isn’t damaged — its checksum matches GitHub’s exactly.
To open ULTRA
In Terminal, run xattr -dr com.apple.quarantine /Applications/ULTRA.app, then open it again.

Don’t take our word for it

Windowscertutil -hashfile ULTRA-windows-x64.exe SHA256
Macshasum -a 256 ULTRA-macos.zip
  1. Check the file is the real one: run the command above in the folder you downloaded to, and compare with the checksum shown here or on the release page.
  2. Scan it: right-click → Scan with Microsoft Defender, or upload it to VirusTotal.
  3. Watch its traffic: any network monitor will show only the connections above.
  4. Read the code: it’s all public.
