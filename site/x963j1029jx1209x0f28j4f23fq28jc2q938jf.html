Sign in to Cloudflare Access first

The terminal sits behind a Google login that Cloudflare checks before any request reaches the Pi. That login cannot run inside a frame, so it has to happen once in its own tab.

  1. Open the terminal in a new tab.
  2. Sign in with Google, then enter your Pi login when ttyd asks.
  3. Come back here — the session cookie is shared across oliverbar.net, so it loads inline from then on.
