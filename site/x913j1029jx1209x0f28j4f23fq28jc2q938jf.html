Pi Terminal Lockdown

Kills remote terminal access to the Raspberry Pi. Anyone mid-command is dropped, not just blocked from starting a new session, and it stays off until you unlock it here. Nobody needs to reload anything — the page reacts within ~5 seconds and the Pi itself within ~10.

Custom Redirects

Add your own trigger words that jump to any path on this site (e.g. /oliverbar.html), a self-serve page (see Custom Pages), or any full URL. Each row has an Advanced toggle for alias words, one-time/scheduled triggers, and random-page mode.

Custom Pages

Paste raw HTML here and it's hosted directly by your Worker — no need to touch the Cloudflare Pages dashboard. Nested paths work too (e.g. slug test/about-us). Copy the generated URL into a Custom Redirect to reach it with a trigger word — opening the raw URL directly won't work, it only loads through the trigger flow.

Games

Each entry shows up as a button on the games hub (reached with the game123 trigger, renameable under Site & Triggers) and opens in a fullscreen embed. URLs must be https://. Note that many sites refuse to be embedded at all — if a game loads blank, that host is sending X-Frame-Options and there's no way around it from this side; self-hosting the game as a Custom Page is the reliable fix.

Chat Moderation

Wipes every message currently stored — visitors on the chat page will see an empty room next time it refreshes. This can't be undone.

Accounts
