Warnings explained

The warnings you may see when you first open ULTRA are about who made it, not about what it does. ULTRA isn’t code-signed yet: signing costs about $200–400 a year on Windows and $99 a year on Mac.

Windows: “Windows protected your PC” (SmartScreen)
What it means
The file isn’t signed and few people have downloaded it yet, so it has no reputation.
What it doesn’t mean
Defender found nothing. SmartScreen shows the same screen for any new unsigned app.
How to open ULTRA
Click More info, then Run anyway.
Mac: “can’t be opened because it is from an unidentified developer” (Gatekeeper)
What it means
The app isn’t signed with an Apple Developer ID or notarized by Apple.
What it doesn’t mean
Apple didn’t scan it and find a problem. It never saw the app.
How to open ULTRA
Right-click ULTRA, choose Open, then Open again.
Mac: “ULTRA is damaged and can’t be opened”
What it means
macOS adds a quarantine flag to downloaded unsigned apps and words it this way.
What it doesn’t mean
The file is intact; its checksum matches GitHub’s.
How to open ULTRA
In Terminal: xattr -dr com.apple.quarantine /Applications/ULTRA.app

The permanent fix is signing: a Windows code-signing certificate (or publishing through the Microsoft Store, which signs for free), and an Apple Developer ID with notarization for Mac.

Passwords and sign-ins

ULTRA never sees, stores or sends your passwords. Pages draw on Microsoft’s WebView2 engine (Windows) and Apple’s WebKit (Mac), the same engines as Edge and Safari, and sign-ins happen inside them.

  • No password saving: ULTRA leaves the engine’s password saving off, so there is no password file to steal. Use a password manager, or your existing browser.
  • Staying signed in: sign-in cookies are kept by the engine itself. On Windows they are encrypted with your Windows account (DPAPI), exactly as in Edge and Chrome.
  • Imports: importing from another browser copies bookmarks, history, open tabs, shortcuts and the search engine. It never reads passwords, cookies or sign-in sessions.
  • Private workspace: its lock password is stored only as an Argon2id hash. Five wrong tries lock it and wipe it. It browses privately (InPrivate) and is hidden from screenshots and screen sharing.
  • Passkeys: handled by the operating system (Windows Hello, iCloud Keychain). ULTRA never holds the keys.

History and data

Everything ULTRA keeps stays in one folder on your computer and is never uploaded: %LOCALAPPDATA%\Ultra on Windows and ~/Library/Application Support/Ultra on Mac. Delete it and ULTRA forgets everything.

What ULTRA connects to

ULTRA makes only four kinds of connection of its own, and none of them carries your browsing. In a live test, a fresh ULTRA left idle made no connections except encrypted DNS lookups (DNS over HTTPS) through the computer’s own resolvers.

Built-in protections

ULTRA blocks more trackers than mainstream browsers do out of the box. On real ad-heavy sites, it let far fewer known ad and tracker requests through than Edge:

ULTRA2 of 33 let through
Edge668 of 753 let through
Known ad and tracker requests that reached the page, as a share of those attempted. Lower is better.
  • Ad and tracker blocking: about 150,000 rules from EasyList, EasyPrivacy, Peter Lowe’s list and uBlock Origin’s filters.
  • Pages can’t control ULTRA: websites can’t reach ULTRA’s own interface, settings or files. That interface is locked down with a strict Content Security Policy.
  • Pop-up limits: sites can’t flood you with new windows.
  • Fullscreen notice: a page going fullscreen shows its real address, so it can’t fake an address bar.
  • Safe updates: updates download only from ULTRA’s own GitHub repository. Each file must match the SHA-256 checksum GitHub published for it, or nothing is installed.
  • Chat safety: encrypted connections only. Each contact’s key is pinned on first use, and a changed key must be verified by its safety code before it is trusted.

How to verify it yourself

You don’t have to take this report’s word for any of it. ULTRA’s full source code is public on GitHub, and every release is built by GitHub Actions from a public commit.

  1. Check that your file is the real one. Compare its SHA-256 with the table above, or with the one shown next to the file on the release page.
    Windowscertutil -hashfile ULTRA-windows-x64.exe SHA256
    Macshasum -a 256 ULTRA-macos.zip
  2. Scan it. Upload it to VirusTotal, or right-click it and choose Scan with Microsoft Defender.
  3. Watch its traffic. Any network monitor (Windows Resource Monitor, Little Snitch on Mac) will show only the connections listed above.
  4. Read the code. Search the repository for any address ULTRA could contact. There are only the ones in this report.
